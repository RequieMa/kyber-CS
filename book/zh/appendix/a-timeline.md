# CS 时间线

- 1822：查尔斯·巴贝奇设计差分机
- 1843：艾达·洛夫莱斯在差分机上设计了第一个**算法**
- 1928：大卫·希尔伯特提出挑战："是否存在一种方法，能够判定一个数学问题是否**可判定**？"
- 1936：阿隆佐·邱奇与艾伦·图灵分别通过**λ演算**和**图灵机**回答了可判定性问题（定义了**可计算性**）
- 1938：康拉德·楚泽制造了 Z1，第一台**电力驱动、可编程**的计算机
- 1945：康拉德·楚泽开发了第一种**高级编程语言** *Plankalkul*
- 1945：存储程序计算机 EDVAC 报告成为**冯·诺依曼架构**的第一份草案 > 二进制；存储设备与 CPU 分离，分别存放数据和指令；5 个逻辑单元
- 1949：莫里斯·威尔克斯提出微程序设计 > 将复杂指令分解为一系列简单指令，即**微码**（在后来的定义中，这被称为**函数**）
- 1951：莫里斯·威尔克斯及其团队发明了**汇编器**，避免直接操作二进制
- 1957：约翰·巴克斯及其 IBM 团队发明了 **Fortran** 和高效的**编译器**，同时为可读性加入了**注释**
- 1958：人工智能之父约翰·麦卡锡发明了 **Lisp**。它很快成为研究者们最喜爱的语言
- 1960 年代：**软件**的概念开始变得重要（在此之前，只有硬件被视为工程，计算机和编程仅被当作数学理论）
- 1963：高德纳开始撰写巨著 *The Art of Computer Programming*（TAOCP）。他为此发明了用于计算机数学排版的 **TeX** 以及**矢量字体**编程语言 METAFONT
- 1964：IBM 推出 029 型键盘打孔机（80 列**打孔卡**成为行业标准）> 键盘与打孔卡交互，然后打孔卡被送入计算机执行
- 1964：约翰·凯梅尼和托马斯·库尔茨希望向非理工科学生推广编程，发明了 **BASIC**（它成为早期便携式 PC 的默认语言。微软至今仍以 VB.Net 的形式支持它）
- 1966：GE 开发了第一个基于网络的数据库管理系统 DBMS。IBM 开发了第一个层次数据库管理系统 IMS，得到 NASA 登月计划的支持
- 1967：Simula 67 在挪威诞生，成为第一种**面向对象编程语言**，引入了**类**、**对象**、**继承**、**虚方法**等概念
- 1968：艾兹赫尔·戴克斯特拉发表 *Go To Statement Considered Harmful*（《goto 语句有害论》）
- 1969：10 月 29 日，第一条消息通过 ARPANET 发送。美国 4 所大学的 4 台计算机通过网络连接。**互联网**由此诞生
- 1969：肯·汤普森为开发 Unix 发明了 B 语言。后来丹尼斯·里奇对其修改，发明了**C 编程语言**
- 1970：**Unix 纪元时间** > 从 1970-01-01 00:00:00 开始计时
- 1970：尼克劳斯·维尔特在苏黎世联邦理工学院发明了面向实用目的的编程语言 **Pascal**。他的名言是"算法 + 数据结构 = 程序"
- 1970：IBM 的埃德加·科德认为层次数据库缺乏便捷的查询能力。他发表了论文"A Relational Model of Data for Large Shared Data Banks"（大型共享数据库的关系模型）。IBM 启动了 System R 项目来研究**关系数据库**的可行性
- 1970：艾伦·凯参与了**个人计算机**和**人机交互**的研究。实验原型 Alto 拥有图形用户界面（**GUI**）和**鼠标**。虽未量产，但后来启发了苹果和 Sun 的微型计算机
- 1971：维尔特在 ACM 发表论文"Program Development by Stepwise Refinement"（逐步精化的程序设计），提出**结构化编程**。他建议不是从可执行程序开始，而是从高度抽象的设计开始，然后逐步精化为具体代码
- 1972：艾伦·凯和他在施乐 PARC 的团队开发了第二种面向对象语言 Smalltalk，它拥有不同于 Simula 的动态消息传递机制
- 1973：Unix 第四版用 C 语言重写。直至今日，操作系统内核仍主要使用 C 语言（Linux 内核超过 98% 的代码由 C 编写）
- 1973：受法国 CYCLADES 网络的启发，罗伯特·卡恩和文顿·瑟夫开始设计一种新的可靠数据传输协议。到 1973 年，他们完成了第一版 **TCP**
- 1974：肯·汤普森和丹尼斯·里奇发表"The UNIX Time-Sharing System"。然而，由于贝尔实验室所属机构 AT&T 的反垄断限制，Unix 无法商业化。这一巧合最终促成了 BSD、GNU 和 Linux 的诞生
- 1975：60 年代，IBM 投入开发 System/360，取得了巨大成功，但其 OS/360 耗费了 5000 人年，被称为"史上最恐怖的软件开发项目"。OS/360 的项目经理弗雷德里克·布鲁克斯出版了**《人月神话》**，探讨大型团队的软件项目管理
- 1976：随着 **Diffie-Hellman 密钥交换（D-H）** 和 **RSA 算法**的发明，非对称加密终于得以实现
- 1979：格伦福德·迈尔斯首次区分了**调试**和**测试**，软件测试成为一门独立学科
- 1970 年代后期：**集成开发环境（IDE）** 的使用逐渐兴起
- 1981：IBM 推出 IBM PC 并成为主流。个人计算机（**PC**）时代开启
- 1983：**TCP/IP** 成为 ARPANET 的默认协议
- 1983：IBM PC 进入中国。然而，DOS 无法处理中文。研究员严援朝带领团队使 DOS 支持中文，称为 CCDOS。严援朝公开了 CCDOS 的全部源代码，后来启发了日本研究人员解决类似问题
- 1983：理查德·斯托曼发起 GNU 计划，倡导软件自由。随后他发表了 *GNU Manifesto*（GNU 宣言）
- 1984：受 Smalltalk 影响，**Objective-C** 作为"给 C 加上面向对象"的语言被发明（在苹果 2014 年推出 Swift 之前，Objective-C 一直是苹果生态系统中最重要的语言）
- 1985：比雅尼·斯特劳斯特鲁普将 Simula 的一些特性集成到 C 的编译器中，创造出一种适合大规模软件开发的新语言。这就是第一版 **C++** 的诞生——一门支持多种编程范式的复杂语言
- 1987：拉里·沃尔想要一个简单的工具，发明了**Perl**——无需编译，可以轻松串联 Unix 上的一系列小工具来完成复杂任务。然而，由于 Perl 语法灵活，难以阅读，成为"只写"语言之一。如今逐渐被 Python 取代
- 1988：艾伦·库珀向比尔·盖茨演示了他正在开发的 GUI。后来这成为了 **Visual Basic**，允许用户通过拖拽组件进行软件开发
- 1989：蒂姆·伯纳斯-李爵士在 CERN 制作了第一个**Web 服务器**、第一个**Web 浏览器**、**URL**、**HTML** 和 **HTTP**。这标志着**万维网（WWW）** 的诞生，网络从此对公众而不仅仅是专业人士变得重要
- 1980 年代：GUI 开始流行。苹果于 1983 年推出 Lisa，1985 年推出 Amiga 1000。Windows 1.0 也于 1985 年发布
- 1980 年代：从 80 年代到 90 年代，Unix 战争成为商业、法律、软件专利等方面的巨大挑战。唯一积极的结果或许是 **POSIX 标准**的诞生
- 1990：吉多·范罗苏姆为圣诞假期做了一个个人项目，但很快它变成了一门广受欢迎的新编程语言 > **Python**。与 Perl 不同，Python 之禅之一是"做一件事最好只有一种方法"
- 1991：林纳斯·托瓦兹将他的个人项目发布到网上 > **Linux**。它采用 **GPL 许可证**，为 GNU 计划提供了可靠的操作系统内核。如今，大多数网络服务、云服务都离不开 Linux
- 1991：菲尔·齐默尔曼编写了第一个面向个人的加密应用程序 > **PGP**。由于其私钥长度超过 128 位，超过了美国加密软件管制规定，美国政府对他展开了刑事调查。他将 PGP 的全部源代码作为一本书出版，以美国宪法第一修正案合法地保护了自己的作品。由此，源代码成为"言论自由"的一部分
- 1995：詹姆斯·高斯林在 Sun 公司设计了一门适合智能电子设备的新语言。为了易用、安全、可移植且高性能，他让它在**虚拟机**上运行，并通过**垃圾回收（GC）** 动态管理内存。这门语言就是 **Java**，其虚拟机为 **JVM**。2008 年 Android 出现时，Java 成为其默认语言，实现了它最初的目标 > **嵌入式**智能设备
- 1995：松本行弘创建了一门来自亚洲的重要编程语言 **Ruby**。他的哲学不同于其他编程语言，是"程序员的幸福"。2004 年，大卫·汉森将 Web 框架 **Ruby on Rails（RoR）** 开源，一度主导了 Web 创业世界
- 1995：布兰登·艾奇被指派为浏览器客户端提供一门"应该像 Java"的脚本语言。作为函数式编程爱好者，他只用了 Java 的一些基本语法，加入了大量函数式编程特性。**JavaScript** 由此诞生——一门实际上与 Java 毫无共同点的语言。2007 年，阿特伍德提出了著名定律 > "任何可以用 JavaScript 编写的应用，最终都会用 JavaScript 编写"
- 1995：早期人们使用 C、C++、Perl 等配合各种自定义框架或脚本来搭建网站。拉斯姆斯·勒多夫用"世界上最好的语言"——**PHP** 终结了这一局面，它成为 Web 社区的标配。"Linux + Apache + MySQL + PHP"一度被视为 Web 开发的*标配技术栈*。如今，只有 Linux 保持不变，其余三者有了许多变体和替代品。PHP 的影响力仍在互联网上延续，例如人们仍可使用 **WordPress** 作为灵活的 Web 开发模板
- 1999：互联网初期，通过网络连接的每台计算机角色相当平等。然而，客户端和服务器端之间逐渐形成了不对称性。1999 年，**点对点网络（P2P）** 的概念出现。客户端开始重新承担更多责任。直至今日，大约每 10 年就会出现新的 P2P 产品（从 **BitTorrent** 到**比特币**及其他**区块链**技术）
- 2000 年代：90 年代末，许多应用有了 Web 版本。然而 JavaScript 在获取数据方面表现不佳，微软为其浏览器添加了 XMLHttp 插件，其他浏览器随后跟进。到 2000 年代初，动态获取数据以 **Web 2.0** 之名流行起来。随着更多业务逻辑可以在浏览器端完成，**前端开发**正式成为一个职位
- 2001：90 年代末，**第二次软件危机**发生。由于缺乏有效的开发管理来应对日益增长的复杂性和规模，许多大型项目面临延期、失败和质量不达预期的问题。2001 年，一群开发者在犹他州聚集，发表了*敏捷软件开发宣言*，以革新软件开发流程
- 2003：**LLVM** 作为强大的编译基础设施被构建。其模块化和完整的**中间表示（IR）** 使其远比同类产品强大。一批新语言因它而诞生，如 **Swift**、**Rust** 和 **Julia**
- 2005：为满足 Linux 内核的**版本控制**需求，林纳斯·托瓦兹设计了名为 **Git** 的工具
- 2008：**GitHub** 上线，作为 Git 项目的托管服务
- 2008：苹果发布首个 **iPhone SDK**，谷歌发布 **Android 1.0 SDK**，移动系统之争拉开帷幕
- 2009：随着网络环境和 CPU 多核的普及，编程语言要么像 C/C++ 那样高效但难学，要么易学但无法充分利用硬件和网络资源。罗伯特·格瑞史莫、罗勃·派克和肯·汤普森设计了一门新语言 **Go**。它基于 **CSP 理论**中的 **goroutine** 和 **channel** 来解决并发和消息传递问题。同时，它出现的时机正值**云计算**和**容器化**趋势刚刚兴起
- 2010：格雷登·霍尔发明了 **Rust**，其理念与 80 年代一门名为 Ada 的旧编程语言相似。与其他语言不同，Rust 提供了无需 GC 的安全内存管理机制，以及简单安全的多线程模式。它达到了 C++ 程序的性能，成为 C/C++ 的替代选择
- 2013：**Docker** 标准化了容器化和沙箱的概念。真正做到了"一次构建，到处运行"。Docker 统一了开发、测试和生产环境。**Kubernetes** 是来自谷歌的开源容器编排系统，可以自动部署容器。它开启了"面向云"的开发方式
- 2014：2010 年，史蒂夫·乔布斯发表 *Thoughts on Flash*，使 **HTML5** 成为热门话题。4 年后，HTML5 作为 Web 应用的新标准发布（限制更少，标准化程度更高）
