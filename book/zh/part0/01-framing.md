# L0 · 立框架——计算机是什么？

```
 ▶ L0  框架          ◀ 你在这里
   L1  软件
   L2  软件 ↔ OS
   L3  指令
   L4  数字逻辑
   L5  比特与物理
```

**问题：** 在问"它怎么工作"之前，我们先问——我们谈论的这个东西，到底是什么？

**核心思想。** 剥掉所有营销辞令，计算机的定义简单得令人惊讶：

> 计算机是一台**能存储数据并按指令处理数据的电子设备**。
>
> - **硬件**就是那台电子设备——真正负责存储和处理的部分。
> - **软件**就是指令和数据——规定*存什么*和*怎么处理*的部分。

这就是全部的分法。**硬件 = 执行者。软件 = 计划与素材。** 一台没有软件的笔记本只是一台取暖器。没有硬件的软件只是一个白日梦。计算，是两者的相遇。

这立刻重新框定了我们的甜甜圈：

- 旋转的形状、旋转的规则、当前的角度——都是**软件**：想法和数据。
- 亮起的屏幕、做乘法的芯片——都是**硬件**：设备忠实地执行计划。

**甜甜圈在这一层。** 我们还不用打开任何代码。我们只是静坐在这团谜面前。三个窗口——字符、方块、圆点——由一个后端驱动。它们显然共享了什么，因为它们一起转。但共享的是什么？不可能是外观，它们看起来毫不相像。所以它们一定共享了外观**之下**的东西。

**悬念。** 三张脸共享的东西，活在"长什么样"之下。要找到它，我们必须走进软件内部，追问：一个程序到底由什么*构成*？→ **L1**

> **一句话旁注。**「抽象」这个词——把"旋转甜甜圈"当作一个想法，而忽略具体怎么画——是计算机科学中最重要的概念。看它在下面每一层反复出现。
