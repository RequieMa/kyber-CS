# 如何阅读本书

> **一句话主线：软件是被抽象出来的「想法」，硬件是忠实地执行指令的「镜子」。**

你即将开始学习计算机科学。在那些名字各异的正式课程——*算法*、*操作系统*、*体系结构*——到来之前，这本书先给你一张它们共同居住的**地图**。

这张地图只有一个形状：一次**下降**。我们从顶端出发，在你每天都在用的软件内部，不断追问同一个顽固的问题：

> *"好……但这件事到底是怎么发生的？"*

每个答案都揭示出下面的一层。我们一路追到底——从屏幕上旋转的形状，到芯片里的电子——然后再爬回顶端，一眼看尽全貌。

## 使用说明

- **不需要编程基础。** 只要你有高中数学水平（正弦、余弦、一点几何），就够了。
- **Part 0 是地图。** 一口气读完约 30 分钟。它用一个贯穿的例子走完整条技术栈。Part 1–3 的每一章都是你在 Part 0 第一次遇到的内容的展开。
- **代码是可选的。** 代码片段只是为了让概念具体化。想读就读，不想读就跳过去。后面没有任何内容依赖你运行它们——但配套仓库（待定）可以让你亲手运行那个旋转的甜甜圈。
- **每章都建立在前一章之上。** 下降是累积的。如果你跳过了，你会错过当前章节正在回答的那个问题。

## 贯穿全程的例子：一个旋转的甜甜圈

一段会旋转的 ASCII 甜甜圈程序（源自 a1k0n 的「donut math」），由**同一个后端**驱动**三张完全不同的脸**：

- **终端**（字符画）　**桌面窗口**（荧光绿方块）　**浏览器**（发光的彩色圆点）

三张脸长得毫不相像，却同步旋转。后端拥有「想法」（甜甜圈的数学与状态），每张脸只拥有自己的「画风」。

这正是整本书要解释的现象。**我们的核心问题：** 这三个窗口看起来毫不相像——它们到底共享了什么？

让我们下降。
